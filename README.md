# Portfolio professionnel — Seifeddine KCHAOU

Site statique HTML/CSS/JavaScript, préparé pour une publication gratuite avec GitHub Pages.

## 1. Personnalisation avant publication

Ouvre `index.html` et remplace les éléments suivants :
- `TON.EMAIL@EXEMPLE.COM` par ton adresse email professionnelle.
- `https://www.linkedin.com/in/TON-PROFIL/` par ton URL LinkedIn.
- `https://github.com/TON-USERNAME` par ton profil GitHub.
- Les dates, établissements et intitulés exacts de tes diplômes.
- Les certifications : conserve uniquement celles que tu as effectivement obtenues et indique leur nom officiel.
- Les expériences : ajoute les postes, stages ou missions réels.
- Les projets : ajoute les résultats, captures d'écran et liens que tu es autorisé à publier.

Les textes qui indiquent « à compléter », « à confirmer » ou « statut » sont des rappels de personnalisation.

## 2. Tester sur ton ordinateur

1. Décompresse le dossier.
2. Ouvre `index.html` dans Chrome, Safari ou Firefox.
3. Vérifie les liens, les textes et l'affichage sur téléphone.

Aucun logiciel spécial n'est nécessaire pour tester le site.

## 3. Publier gratuitement avec GitHub Pages

1. Crée ou connecte-toi à un compte sur https://github.com/.
2. Clique sur **New repository**.
3. Nomme le dépôt exactement `TON-USERNAME.github.io` (remplace TON-USERNAME par ton identifiant GitHub).
4. Choisis **Public**, puis crée le dépôt.
5. Dans le dépôt, clique sur **Add file → Upload files**.
6. Téléverse les trois fichiers du site : `index.html`, `style.css` et `script.js` (pas le dossier parent).
7. Clique sur **Commit changes**.
8. Va dans **Settings → Pages**.
9. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
10. Choisis la branche **main** et le dossier **/(root)**, puis clique sur **Save**.
11. Après le déploiement, ton site sera accessible à `https://TON-USERNAME.github.io/`.

La première publication peut prendre quelques minutes.

## 4. Mise à jour

Pour modifier le portfolio, édite le fichier concerné puis téléverse la nouvelle version dans le même dépôt en remplaçant l'ancien fichier.

## 5. Sécurité et confidentialité

- Ne publie jamais de mots de passe, clés API, adresses privées ou informations confidentielles.
- N'ajoute pas de rapports de pentest, journaux ou captures contenant des données réelles sensibles.
- Publie uniquement des projets et documents que tu es autorisé à partager.
- Vérifie les liens et les informations personnelles avant de rendre le dépôt public.

## Structure

- `index.html` : contenu et sections
- `style.css` : apparence, couleurs et responsive design
- `script.js` : menu mobile et année automatique
